### 🧩 Плагины для Obsidian

| Плагин | Что делает |
|---|---|
| [**Канбан-календарь**](https://github.com/DaniilSemizhonov/obsidian-kanban-calendar) | Календарь задач с Kanban-досок: сроки из свойств заметок, перенос мышью, мини-календарь |
| [**Железо**](https://github.com/DaniilSemizhonov/obsidian-zhelezo) | Панель тренировки: план с весами по микроциклам, отметки упражнений, запись в ежедневную заметку |
| [**Telegram-статьи**](https://github.com/DaniilSemizhonov/obsidian-telegram-rich) | Отправка заметок в Telegram как Rich Message |
| [**HTML-вставки**](https://github.com/DaniilSemizhonov/obsidian-html-vstavki) | Встраивание HTML-файлов прямо в заметки |
| [**Study Dashboard**](https://github.com/DaniilSemizhonov/Study-Dashboard-Ebbinghaus) | Интервальные повторения по кривой Эббингауза: очередь и календарь повторений |
| [**Stipuha**](https://github.com/DaniilSemizhonov/Stipuha) | Финансовый трекер: сколько можно потратить до конца месяца |
| [**Copy wikilink**](https://github.com/DaniilSemizhonov/obsidian-copy-wikilink) | Копирование `[[ссылки]]` на любой файл из контекстного меню |

Плюс русские переводы для [Kanban](https://github.com/DaniilSemizhonov/obsidian-kanban-ru) и [Office Reader](https://github.com/DaniilSemizhonov/obsidian-office-reader-ru).
